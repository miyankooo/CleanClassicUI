# CleanClassicUI

Minimalist restyling of the default WoW Classic Era interface, plus a handful of quality-of-life tweaks. Frame layout stays with Blizzard's Edit Mode.

## Features

### Action bars

- Clean action, stance and pet buttons with tooltip-style borders and cropped icons
- Stock bar art and gryphon end caps hidden
- XP and reputation bars restyled, with detailed mouseover tooltips

### Bags and items

- Bordered bag buttons and stacked bag windows
- Bank bags open together with the bank
- Quality-colored item borders in bags, bank, character and inspect panels
- Quest items bordered in gold
- Item level shown in item tooltips

### Combat

- Minimal cast bar without border art, spark or icon
- Color-coded buffs and debuffs, with remaining minutes on long durations
- Grey-tinted player, target, target-of-target and pet frames
- Restyled raid frames, breath and fatigue timers
- Draggable loot roll frames that remember their position

### Map and chat

- Clean minimap with grey-ringed draggable buttons and scroll-to-zoom
- Smaller centered world map with scroll-to-zoom
- Class-colored chat names
- Shift-click a chat tab to jump to the newest message

### Extras

- Tooltip anchor placeable through Edit Mode
- Group-finder eye docked next to the micro menu
- Draggable clock and alarm panel that remembers its position

## Installation

1. Copy the `CleanClassicUI/` folder into `World of Warcraft/_classic_era_/Interface/AddOns/`.
2. Restart the game or `/reload`.
3. Enable **Clean Classic UI** in the AddOns list.

## Moving frames

The addon never moves anything. Arrange your UI with Edit Mode (`/editmode`) and the addon keeps it all styled.

## Requirements

WoW Classic Era 1.15.x.
